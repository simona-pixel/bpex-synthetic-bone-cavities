# Hollow tibial segment attribution

Source geometry: Keast M, Bonacci J and Fox A. Statistical Shape Model of the Tibia, version 4. Figshare. https://doi.org/10.6084/m9.figshare.20454462.v4 . Source licence: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/ .

The example reuses the external right tibia of public case 102480, aligned using the study preparation protocol. The synthetic cavity was generated with the preserved v3 external profile. A central 40-mm segment was clipped from the outer volume and the longer cavity was subtracted using Blender. This is a modified derivative, not an original source mesh. Authors of the cavity workflow: Simon Arvati, François Luc, Laurent Delbreilh, Agnès Liard-Zmuda and Alexis Lubet.

The derived STL is shared for review with the same CC BY 4.0 attribution terms as its source geometry. This does not license independently authored source code; see LICENSE_STATUS.md. No physical manufacture or functional validation is established by this digital example.
